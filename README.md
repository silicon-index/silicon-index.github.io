# Silicon Index 🖥️📊

> An open-source, community-verified PC hardware market index and fair value screener.

Silicon Index aggregates component pricing across major retail and secondary markets to calculate real-time fair value scores, detect artificial market inflation (scalping), and provide transparent analytics for tech enthusiasts.

---

## 🏛️ Ecosystem & Repositories

The project is structured modularly across specialized repositories within the `silicon-index` organization to ensure data hygiene, operational security, and performance:

| Repository | Access | Purpose |
| :--- | :--- | :--- |
| **`silicon-index.github.io`** | **Public** | Main user interface, live screener tables, and documentation. |
| **`museum`** | **Public** | Archival hardware data and historical tech retrospective UI. |
| **`blog`** | **Public** | Market trend analysis, teardowns, and algorithm updates. |
| **`backend-api`** | **Private / Core** | REST/Serverless endpoints, database schemas, and contributor auth. |
| **`market-scrapers`** | **Private / Core** | Automated indexers, aggregation engines, and market sanitizers. |
| **`admin-dashboard`** | **Private** | Internal moderation console for verifying incoming price points. |
