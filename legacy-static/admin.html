Contributor Identity

Signed-in submissions are attributed to the account's username and become Trusted Contributor once approved. Submissions made while signed out are attributed to a random per-browser pseudonymous ID (e.g. anon-4f9k2p1x, stored in that browser's localStorage) and become Anonymous Contribution once approved. Real IP addresses are intentionally never collected client-side — this site has no server to see them, and capturing them here would break the "no PII" whitelist rule in DEV-GUIDE.md. IP-based dedup/trust, if ever added, belongs server-side in silicon-index-backend-api (see Phase 5 in dev-index.md).
